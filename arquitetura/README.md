# FastReport — Base de Arquitetura

Documentação de referência do produto FastReport, extraída dos repositórios existentes e unificada como base de planejamento para o novo app.

Todo o conteúdo é **agnóstico de stack** — descreve o "quê" (regras, fluxos, dados), não o "como" (tecnologia).
